# 亚琛工业大学听觉技术与声学研究所新址！

经过约两年的建设，我们听觉技术与声学研究所（IHTA）搬进了新落成的 Cube 3 大楼。新址在德国亚琛，地址是 Kopernikusstraße 18。

新楼里有一整层是研究所的办公室和会议室。另一层把我们的机械车间、电气车间和所有实验室都集中到了一起。如今，我们也跻身设备最齐全的声学研究所之列。对此，我们既感激，也自豪！

Cube 3 为我们提供了哪些新的测量和实验条件？

1. **半消声室。** 面积约 95 平方米，体积约 520 立方米，符合 DIN EN ISO 3745 的 1 级精度要求。下限截止频率为 100 Hz，测量频率上限可达 20 kHz。
2. **全消声室。** 面积约 50 平方米，体积为 316 立方米，同样符合 DIN EN ISO 3745 的 1 级精度要求，可测频率范围为 125 Hz 至 20 kHz。
3. **混响室。** 体积约 300 立方米。室内表面对声音有很强的反射，形成扩散声场，可以在这里按 ISO 354 进行测量。
4. **虚拟现实实验室。** 这是一间声学虚拟现实（VR）实验室，按 ITU-R BS.1116 对听音室的要求设计。
5. **三间听力测试隔声室。** 每间都采用“房中房”结构，并内置吸声构件，符合常用听力测试标准的要求。
6. **机械车间和电气车间。**

眼下，我们还在忙着拆箱，准备实验室，好让接下来的实验和测量能顺利开展。我们希望到 2027 年初，大部分实验装置都能投入使用，其中包括我们的 68 通道扬声器阵列 SCaLAr，以及能快速测量个体头相关传递函数（HRTF）的 64 通道系统。

后续进展，敬请期待！
